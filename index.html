Einmal verbinden

Deine To-dos liegen in deinem privaten GitHub-Repo termed-todo-data. Damit die App sie lesen und abhaken kann, braucht sie einmal einen Schlüssel von GitHub.

  1. Öffne github.com → Neuer Schlüssel.
  2. Name: „To-Do-App“, Ablauf: 1 Jahr.
  3. Repository access: Only select repositories → termed-todo-data.
  4. Permissions → Repository → Contents: Read and write.
  5. „Generate token“ tippen, den Schlüssel kopieren und hier einfügen.

Der Schlüssel bleibt nur auf diesem Gerät gespeichert und darf nur dieses eine Repo lesen und schreiben.
